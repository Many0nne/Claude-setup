Ne pas lancer les commandes de tests sans y être explicitement invité.

**Why:** L'utilisateur préfère exécuter les tests lui-même et partager le résultat si besoin.

**How to apply:** Après une série de modifications, proposer de lancer les tests mais ne pas les lancer soi-même. Si l'utilisateur partage un fichier de résultats (ex. test_feedback.md), lire ce fichier et corriger les erreurs.
