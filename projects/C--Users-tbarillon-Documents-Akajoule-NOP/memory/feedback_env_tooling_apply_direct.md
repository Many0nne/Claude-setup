Quand je travaille sur l'outillage de l'environnement NOP (`scripts/*.ps1`, `CLAUDE.md` racine, skills perso) et que je repere une autre amelioration de cet outillage, je l'applique directement puis je la signale dans **Modifie**, sans la laisser en proposition dans **Trouve**.

**Why:** l'utilisateur l'avait autorise explicitement ("tu peux les appliquer direct") et a ete agace que je laisse quand meme un point en "Trouve" (2026-10-15).

**How to apply:** exception a [[feedback_no_out_of_scope_changes]], limitee a l'outillage de l'environnement. Le code applicatif back/front reste soumis a l'accord prealable.
